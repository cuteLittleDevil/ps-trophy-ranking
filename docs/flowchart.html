Sony API Flowchart

按 Online ID 拉取奖杯

ps-trophy-ranking · internal/psn.Lookup · resty · 非官方 PSN 接口

流程图 (Flowchart) — 解析 accountId 是短路：命中则跳过后续查找。过期先 refresh，失败再 /authorize。左侧实线为跳过，右侧虚线为失败出口。

AUTH

NPSSO → token

  • • 凭证只来自环境变量或 .env
  • • access_token 未过期则跳过本阶段
  • • 过期先 refresh，失败再 /authorize + /token
  • • /authorize 必须停在 302，从 Location 取 code
  • • dump / 日志不含 token

RESOLVE

Online ID → accountId

  • • GET /me/profiles：400/404 继续；命中自己则跳过搜索
  • • POST /universalSearch：只接受精确 Online ID
  • • 搜索命中则不打 profile2
  • • GET /profile2：仅搜索未命中时的兜底
  • • 401 凭证无效；429 / 其它非 2xx 暂时无法同步

TROPHY

trophySummary

  • • GET /trophy/v1/users/{accountId}/trophySummary
  • • 403 未公开；404 找不到用户；429 上游限流
  • • 只用 earnedTrophies 本地计分，不用 trophyPoint
